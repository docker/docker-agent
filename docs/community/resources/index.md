Explore projects, talks, tutorials, and articles from the Docker Agent community.

Community projects and third-party content are independently maintained. Inclusion
here does not imply endorsement or support by Docker. Docker-published videos are
identified by their publisher.

Older resources use the former name **cagent** and may describe older releases.
Check commands and configuration against the current documentation before using them.

## Suggest a resource

To add a resource or correct an entry, open a pull request using the
[contributing guide](../contributing/index.md). Include the original project or
publication link, a short description, maintainer or author/speaker attribution,
and the content or documentation language. Round video durations to the nearest
whole minute (`N min`). Include source-published reading times when available and
dates (`YYYY-MM-DD`), clearly labeling publication, update, series-start, or
list-addition dates. Do not guess missing metadata; use **Not provided** when the
source does not supply it.
