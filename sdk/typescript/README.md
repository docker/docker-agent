# @docker/docker-agent-ts-sdk

TypeScript types for the docker-agent API (`docker agent serve api`): request
and response bodies, sessions, agent configs and every event streamed by a
session. They are generated from the Go types the server encodes, so they
match the JSON it actually sends.

```ts
import type { AgentStreamingEvent } from '@docker/docker-agent-ts-sdk';

function render(event: AgentStreamingEvent) {
  switch (event.type) {
    case 'agent_choice':
      return event.content;
    case 'tool_call':
      return event.tool_call.function.name;
  }
}
```

The same types are also available as a JSON Schema (2020-12) in
`schemas/docker-agent.schema.json`, one `$defs` entry per type.

## Reading the types

- An optional property (`name?: T`) is omitted from the JSON when empty.
- `T | null` means the server may send `null`, usually for an unset list or
  object.
- Timestamps are RFC 3339 strings.
- `AgentStreamingEvent` is a union discriminated by `type`.

## Development

Everything under `src/generated/` and `schemas/` is generated by
[`gen`](gen) and committed. Don't edit it by hand; from the repository root:

```sh
task generate-ts # regenerate after changing Go API types
task check-ts    # what CI runs: fails when the output is stale or doesn't type-check
```

`gen/config.go` lists the Go types to expose. Types with a custom
`MarshalJSON` need a schema in `gen/overrides.go`: the generator refuses to
guess their shape.
